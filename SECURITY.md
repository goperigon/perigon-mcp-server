# Security policy

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report them privately using one of these channels:

1. **GitHub private vulnerability reporting** (preferred):  
   [Create a security advisory](https://github.com/goperigon/perigon-mcp-server/security/advisories/new)

2. **Email fallback:**  
   [support@perigon.io](mailto:support@perigon.io) with subject line `Security report: perigon-mcp-server`

Include:

- Affected endpoint, tool, or component
- Steps to reproduce
- Expected vs. actual behavior and impact

We will acknowledge your report and follow up as we investigate.

## Scope

- The hosted MCP service at `https://mcp.perigon.io`
- The `main` branch of this repository

## Guidelines for researchers

- Do not access data belonging to other users or organizations.
- Do not run destructive or denial-of-service tests against production.
- Give us reasonable time to fix confirmed issues before public disclosure.

## Response

We do not publish a fixed SLA. We treat legitimate reports seriously and will communicate status as we work on a fix.
